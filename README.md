# Auto Input

Windows 下的轻量延时自动输入工具。界面基于 Python 标准库 `tkinter`，自动输入基于 Windows `SendInput`，不引入第三方运行依赖。

## 运行

```powershell
uv run python -m auto_input
```

## 功能

- 粘贴一段文字后，按设定的开始延时自动输入到当前焦点窗口。
- 支持固定字间延迟。
- 支持随机字间延迟，可设置最小值和最大值。
- 支持取消正在等待或正在输入的任务。
- 支持全局急停热键，默认是反引号/波浪号键（反引号键 / `~`），也可配置为 `Esc`、`F12`、`Ctrl+Shift+Q` 等。
- 窗口可缩放，文本区域会随窗口大小调整。

## 注意

开始后请在倒计时结束前切换到目标输入框。若目标程序以管理员权限运行，本工具也需要同等权限才能向它发送输入。
